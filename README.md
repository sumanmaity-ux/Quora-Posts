# Quora Posts
A Quora-inspired web application built using Node.js and Express.js that demonstrates RESTful routing and CRUD operations. Users can create, view, edit, and delete posts.

## Features

- Create a new post
- View all posts
- View a post in detail
- Edit existing posts
- Delete posts
- Display username and post content

## Technologies Used

- Node.js
- Express.js
- EJS
- HTML
- CSS
- JavaScript

## Concepts Used

- RESTful Routing
- CRUD Operations
- HTTP Methods
- Express.js Routing
- Dynamic web Pages

## CRUD Operations
- **Create** - Create a new post
- **Read** - View posts and post details
- **Update** - Edit an existing post
- **Delete** - Delete a post
